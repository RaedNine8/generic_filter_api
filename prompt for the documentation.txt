## PRIMARY OBJECTIVE

Turn the current project into a technically coherent, polished, credible open-source project that is ready to showcase publicly.

The project must NOT be positioned as a CRUD generator, CRUD framework, or basic CRUD tooling.

The intended concept is a generic, extensible query/filtering layer that can integrate into existing applications across multiple backend and frontend ecosystems, with an optional natural-language "Filter Copilot" that compiles natural language into the same structured filtering representation used by the application.

The project is intentionally framework-flexible.

Target backends:

* FastAPI + SQLAlchemy
* Express.js + Prisma
* Spring Boot + JPA

Target frontends:

* React
* Next.js
* Angular
* Vue

Do not incorrectly narrow the product to FastAPI + Angular.

The default/reference implementation may currently be FastAPI + SQLAlchemy + Angular, but the architecture and product positioning must clearly communicate the broader multi-stack design.

# PHASE 5 — STRENGTHEN THE NATURAL-LANGUAGE LAYER

Keep Filter Copilot deliberately constrained.

The architecture should be:

Natural language
↓
LLM
↓
structured Filter AST
↓
schema validation
↓
semantic validation
↓
authorization/capability validation
↓
human-readable preview
↓
explicit approval
↓
existing FilterX execution engine

Do NOT present this as an autonomous unrestricted database agent.

Describe it as a constrained agentic workflow / natural-language compiler.

Strengthen validation so the system rejects:

* nonexistent fields
* unsupported operators
* invalid types
* unsupported relationship paths
* unsupported operations
* inaccessible fields
* invalid values
* malformed filter trees

Where practical, add explicit field capabilities such as:

* filterable
* sortable
* groupable
* searchable
* exposed-to-agent

Example:

fields:
User.email:
filter: true
sort: true
group: false
agent: true

User.salary:
filter: false
sort: false
group: false
agent: false

Do not expose every database field automatically to the agent.
